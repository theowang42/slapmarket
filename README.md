# US Market Pulse

美股盘中看板。一屏看完大盘、板块、异动、自选，暗色极简，开盘后打开就不用动了。

```bash
npm start   # → http://localhost:5173
```

无依赖，Node ≥ 18 直接跑。

## 一屏都有什么

| 区域 | 作用 |
|---|---|
| 顶栏 | 交易时段 + 距开/收盘倒计时（美东时间）、全市场涨跌家数条 |
| 指数条 | 标普 / 纳指 / 道指 / 罗素 2000 / VIX，带当日分时线，虚线是前收 |
| 板块热力图 | 主视图。方块大小 = 实时市值，颜色 = 当日涨跌，按 11 个板块分组 |
| 板块排行 | 11 个行业 ETF 按涨跌幅排序的双向条形图；悬停会把热力图里其它板块压暗 |
| 今日异动 | 全部成分股的领涨 / 领跌；悬停会在热力图里把那只框出来 |
| 自选 | `config.js` 里的列表，盘前盘后单独标注 |

鼠标停在热力图任意方块上出详情。按 `R` 强制刷新（绕过服务端缓存）。

## 改配置

只需要动 [`config.js`](config.js)：

- `WATCHLIST` — 自选股，顺序即展示顺序
- `SECTORS[].stocks` — 热力图里每个板块画哪些股票（市值自动取，不用维护）
- `INDICES` — 顶部指数
- `HEAT_CLAMP` — 热力图配色的饱和上限，默认 `3`（即 ±3% 到最深）。
  日内波动大的时候调到 4~5 会更耐看

行情符号用 CNBC 的写法：普通股票直接写 ticker，A/B 股用点号（`BRK.B`），指数前面带点（`.SPX`）。
改完存盘刷新页面即可，服务端缓存最多 3 分钟，想立刻生效就按 `R`。

## 数据

数据源是 CNBC 的公开行情接口，免 key，**报价约 15 分钟延迟**。

- 服务端代理并缓存（报价 60s、分时 180s），浏览器不直连，没有跨域问题
- 拉取失败时回退到上一份缓存，页面不会被打空
- 刷新节奏跟着盘口走：交易中 30s，盘前盘后 60s，休市 5min；切回标签页会立刻补一次

## 已知边界

- **交易时段没有计入美股节假日**。感恩节、圣诞这类休市日，顶栏会照常显示"交易中"，
  但报价不动。要精确的话在 `server.js` 的 `marketSession()` 里加一张节假日表。
- 板块涨跌幅取的是对应 SPDR 行业 ETF，跟成分股加权结果会有小幅出入（ETF 更贴近真实板块表现）。
- 热力图只画 `config.js` 里列出的成分股，不是全市场，看的是大票的脸色。
