# US Market Pulse

美股盘中看板。一屏看完大盘、板块、异动、自选，暗色极简，开盘后打开就不用动了。

```bash
npm start   # → http://localhost:5173
```

无依赖，Node ≥ 18 直接跑。

## 一屏都有什么

| 区域 | 作用 |
|---|---|
| 顶栏 | 交易时段 + 距开/收盘倒计时（美东时间）、全市场涨跌家数条 |
| 指数条 | 标普 / 纳指 / 道指 / 罗素 2000 / VIX，带当日分时线，虚线是前收 |
| 板块热力图 | 主视图。方块大小 = 实时市值，颜色 = 当日涨跌，按 11 个板块分组。成分股每天自动跟随指数调仓 |
| 板块排行 | 11 个行业 ETF 按涨跌幅排序的双向条形图；悬停会把热力图里其它板块压暗 |
| 今日异动 | 全部成分股的领涨 / 领跌；悬停会在热力图里把那只框出来 |
| 自选 | `config.js` 里的列表，盘前盘后单独标注 |

鼠标停在热力图任意方块上出详情。按 `R` 强制刷新（绕过服务端缓存）。

## 改配置

只需要动 [`config.js`](config.js)：

- `WATCHLIST` — 自选股，顺序即展示顺序
- `SECTORS[].pin` — 强制画进某个板块的股票（用于还没进标普 500 的新股，见下）
- `INDICES` — 顶部指数
- `HEAT_CLAMP` — 热力图配色的饱和上限，默认 `3`（即 ±3% 到最深）。
  日内波动大的时候调到 4~5 会更耐看

行情符号用 CNBC 的写法：普通股票直接写 ticker，A/B 股用点号（`BRK.B`），指数前面带点（`.SPX`）。
改完存盘刷新页面即可，服务端缓存最多 3 分钟，想立刻生效就按 `R`。

## 成分股怎么来的

热力图的成分股**不是写死的名单**，是每天从 SSGA 官网拉 11 只 SPDR 行业 ETF 的
官方每日持仓（xlsx），按权重自动选出来的。这 11 只 ETF 的持仓加起来正好是标普 500，
所以指数调仓、并购退市都会自动跟上，不用手工维护。

- 选取规则见 `HOLDINGS_PICK`：按权重从大到小累加到 `coverage`，再用 `min`/`max` 夹住。
  集中度高的板块自然少画几只，分散的多画几只
- 前端保证**画出来的每一格都写得下代码**：按板块框面积定数量，再剔掉又细又长写不下的格子。
  字宽是用 canvas 实测的，不靠字数估——估算会低估 M、W 这类宽字母，AMGN、SCHW 就会顶出格子
- **双重股权会合并**：GOOGL/GOOG、FOXA/FOX、NWSA/NWS 在 ETF 里是两条持仓，
  但行情源给的是整家公司的市值，两条都画会让 Alphabet 占两倍面积。只保留权重大的那个类别
- 持仓缓存在 `data/holdings.json`，12 小时刷一次。过期时先返回旧的、后台再刷，
  页面不会因为等 SSGA 而卡住；抓不到就一直用磁盘上的旧数据

### pin：还没进指数的公司

行业 ETF 只包含标普 500 成分股，新上市的公司通常要满一年才有资格纳入。
这类公司要手动 pin 进来：

```js
{ key: 'indu', name: '工业', etf: 'XLI', pin: ['SPCX'] },
```

现在 pin 了一个 SpaceX（`SPCX`，市值已过万亿，但还不在标普 500 里）。
等它真正进了指数，把 pin 删掉即可，删不删都不会重复。

## 数据

行情源是 CNBC 的公开接口，成分股来自 SSGA，都免 key，**报价约 15 分钟延迟**。

- 服务端代理并缓存（报价 60s、分时 180s），浏览器不直连，没有跨域问题
- 拉取失败时回退到上一份缓存，页面不会被打空
- 刷新节奏跟着盘口走：交易中 30s，盘前盘后 60s，休市 5min；切回标签页会立刻补一次

## 已知边界

- **交易时段没有计入美股节假日**。感恩节、圣诞这类休市日，顶栏会照常显示"交易中"，
  但报价不动。要精确的话在 `server.js` 的 `marketSession()` 里加一张节假日表。
- 板块涨跌幅取的是对应 SPDR 行业 ETF，跟成分股加权结果会有小幅出入（ETF 更贴近真实板块表现）。
- 热力图画的是标普 500 里各板块权重靠前的公司（外加 pin 的），不是全市场，看的是大票的脸色。
- **板块框的大小是准的，板块内部的格子大小是相对的。** 板块框按该板块完整市值定大小，
  但内部只画得下前几只，它们会撑满整个框。所以格子反映的是"这几只之间"的相对大小，
  不是各自占整个板块的份额——小板块尤其明显。窗口拉大会画出更多只，失真随之变小。
  （试过让板块框跟着画出来的部分缩，结果小板块一缩就崩：房地产前两只只占板块两成半市值，
  框缩到四分之一后连一格都放不下。板块之间的比例更重要，所以保它。）
- `data/holdings.json` 跟着仓库一起提交了，作用是首次启动、SSGA 又刚好连不上时的兜底。
